# Security policy

Skyframe is an early-stage offline-first desktop prototype. There is no hosted game service or supported online account system at this stage.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's **Report a vulnerability** / private security advisory feature for this repository when it is enabled. If private reporting is unavailable, contact the repository owner privately before disclosing details publicly.

Include the affected version or commit, the environment, reproduction steps, and any relevant impact. Do not include real credentials, personal data, or unrelated private information.

## Scope

Security issues in the application, build scripts, dependencies, and repository automation are in scope. The project currently does not provide a network service; do not assume that planned online features exist.
